# Pixel Assistant (`pixel-assistant`)

**Google Pixel 7（Android 13 / 14 / 15）向け**の専用アシスタントアプリです。

1. **LINE & Bumble**: メッセージ画面を開くと、AI（Gemini 2.5 Flash 無料枠 / スマートモック）が文脈に合わせた **4つの返信プラン** を提示。タップで入力欄に挿入。
2. **Netflix**: 英語字幕を画面内で検知して **重ならない位置に日本語字幕帯（ドラッグで移動可能）** を表示。広告再生時は自動で音声をミュートします。

---

## 🔒 安心・安全設計のポイント

- **安全第一（アカウントBAN防止）**:
  - 初期設定は **「入力欄に下書きをセットするだけ（送信ボタンは自分でタップ）」** になっています。意図しない誤送信や利用規約違反を防ぎます。
  - もちろん、設定画面で「選択時に自動送信」をONにすることも可能です。
  - 「✍️ 直に入力」ボタンを押せば、アシスタントがサッと最小化されて普段通りキーボードで手入力できます。
- **Gemini API 無料枠の完全保護**:
  - アプリ内に **「無料枠クォータマネージャー」** を内蔵。
  - 1分あたり10回（RPM 10）、1日あたり1,500回（RPD 1,500）を超えないよう自動で制御。上限に達した場合は、安全にオフラインのスマートモックへ自動フォールバックします。
  - クレジットカードを登録しない無料プロジェクトを使用するため、**料金が勝手に発生することは絶対にありません**。

## 🔑 Gemini APIキーの取得方法（無料・クレカ不要・2分）

1. スマホまたはPCのブラウザで **[Google AI Studio (API Keys)](https://aistudio.google.com/apikey)** を開きます。
2. お手持ちの Google アカウントでログインします。
3. 青色の **「Create API key」** ボタンをタップします。
4. 「Create API key in new project（新しいプロジェクトで作成）」を選択します。
5. 発行された `AIzaSy...` から始まるキーをコピーします。
6. Pixel Assistant アプリのトップ画面にある「Gemini API Key」の欄に貼り付けて **「設定を保存」** を押せば完了です！

> 💡 **APIキーがなくても動作します**: キーが未入力の場合でも、内蔵の「スマートモックエンジン」が映画・食事・休日などの話題を判別し、4つの自然な返信案を即座に作成します。

## 🎬 Netflix の動作と広告倍速について

### 1. 字幕翻訳（デュアル表示）
- Netflixの字幕設定を「英語」にしておくと、アプリが英語字幕を検知して **画面上部または字幕のすぐ上に日本語翻訳帯** を表示します。
- **重なり防止**: 元の英語字幕に重なって見えなくならないよう、上下に並ぶ形で配置しています。帯の「⋮⋮ ドラッグで移動」を指でなぞると、画面上の好きな位置へ自由に動かせます。

### 2. 広告の倍速について（スマホアプリの仕様）
- **Netflix公式Androidアプリの中**は、強固なDRM（著作権保護）と専用プレーヤーで守られているため、Android OSの仕様上、外部アプリから公式アプリ内の動画再生速度を強制的に倍速にするAPIは提供されていません。
- そのため、本アプリでは **「広告が流れている間だけ自動でメディア音量をゼロ（ミュート）にし、本編に戻ったら音量を復元する」** 快適化機能を提供しています。
- **💡 スマホで広告4倍速スキップを使いたい場合**:
  - Pixel 7のブラウザ（Chrome拡張機能が動く「Kiwi Browser」など）で Netflix を開いて視聴する場合、先ほど作成した [`netflix-dual-subs`](https://github.com/ikeda305pixel-alt/netflix-dual-subs) を読み込むことで、**スマホ上でも広告の4倍速・8倍速スキップ＆日英デュアル字幕が完全動作**します！

## 📱 Pixel 7 へのインストール手順（PC不要）

### ステップ 1: APKファイルのダウンロード
1. 本リポジトリの **[Actions](../../actions)** タブを開きます。
2. 一番上のワークフロー（最新のコミット）をタップします。
3. ページ下部の **Artifacts** にある `pixel-assistant-debug.apk` をタップして Pixel 7 にダウンロードします。

### ステップ 2: インストールと権限許可（初回のみ）
1. ダウンロードした APK ファイルをタップして「インストール」します。
   - ※「提供元不明のアプリ」警告が出た場合は「許可」してください。
2. Pixel 7 の Android 13 / 14 ではセキュリティのため「制限付き設定」がかかる場合があります：
   - Pixelの「設定」→「アプリ」→「Pixel Assistant」を開く。
   - 右上の「︙（3点リーダー）」をタップし、**「制限付き設定を許可」** をタップします。
3. アプリを起動し、画面のボタンから以下の2つをONにします：
   - **「ユーザー補助設定」**: `Pixel Assistant` を探してONにする。
   - **「他のアプリの上に重ねて表示」**: 許可をONにする。

これで準備完了です！LINEやBumbleを開くと、未返信メッセージがある時に画面下部に返信案が自動で浮かび上がります。
